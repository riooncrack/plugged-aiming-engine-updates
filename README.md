# Plugged Aiming Engine updates

Download the complete application ZIP from [Releases](https://github.com/riooncrack/plugged-aiming-engine-updates/releases/latest). GitHub's automatically generated source archives contain this release repository, not the application.

A license issued by the separate **Plugged Aiming Engine** KeyAuth app is required. PluggedVision licenses belong to a different application.

The application verifies the Ed25519-signed `stable.json` feed and the downloaded ZIP's size and SHA256 before preparing an update. Installation waits until the editor and hosted worker are stopped; it retains a backup and existing saved profiles. Refer to the included readme before switching versions.

This repository hosts compiled product releases and public update metadata. Private application sources, signing keys, license keys and test binaries are not distributed here.

Security checks add resistance to specific tampering attempts; no local client is guaranteed unpatchable. Themida is not included in version 1.0.9.
